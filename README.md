# Task-5
Exploratory Data Analysis (EDA)
## 📋 Project Overview
This repository contains an exploratory data analysis (EDA) of sales transaction data, focusing on understanding:
- Sales patterns and trends
- Customer behavior insights
- Product performance metrics
- Regional sales distributions

Key features analyzed:
- Product categories
- Sales representatives' performance
- Regional trends
- Payment methods and sales channels

## 📁 Dataset Details
**File:** `sales_data.csv` (1000 transactions, 14 features)

**Features Include:**
- `Product_ID`, `Sale_Date`, `Sales_Rep`, `Region`
- `Sales_Amount`, `Quantity_Sold`, `Product_Category`
- `Unit_Cost`, `Unit_Price`, `Customer_Type`
- `Discount`, `Payment_Method`, `Sales_Channel`
- `Region_and_Sales_Rep`

## 🔍 Key Insights
### Product Performance
- **Top Performing Category:** Furniture dominates sales
- Price vs. Quantity relationships
- Discount impact analysis

### Regional Analysis
- **Highest Sales:** North region (34.2% of total sales)
- Regional sales strategy recommendations

### Customer Behavior
- Returning vs. new customer patterns
- Preferred payment methods
- Sales channel effectiveness

## 📊 Visualization Highlights
1. **Product Category Sales**
   - Bar chart comparing total sales across categories
   - Furniture leads with highest revenue generation

2. **Regional Sales Distribution**
   - Pie chart showing regional market share
   - North > South > West > East regional performance

3. **Temporal Analysis**
   - Monthly/Quarterly sales trends (based on `Sale_Date`)
   - Seasonal patterns identification

## 🛠 Technologies Used
- **Python 3.8**
- **Libraries:**
  - Pandas (Data manipulation)
  - Matplotlib & Seaborn (Visualizations)
  - NumPy (Numerical operations)
